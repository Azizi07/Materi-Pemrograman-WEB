Bab 01

Pengantar Web

Sebelum menulis kode, penting memahami apa itu web, bagaimana ia bekerja, dan kenapa ada begitu banyak jenis website berbeda di internet.

Sejarah Perkembangan Web

dasar
World Wide Web (WWW) diciptakan oleh Tim Berners-Lee pada tahun 1989 di CERN, awalnya untuk memudahkan para peneliti berbagi dokumen. Web terus berkembang melalui beberapa era besar:
EraPeriodeCiri Utama
Web 1.01991 – awal 2000-anHalaman statis, hanya baca (read-only), sedikit interaksi
Web 2.0Pertengahan 2000-an – sekarangInteraktif, media sosial, konten dibuat pengguna (read-write)
Web 3.0Berkembang saat iniWeb cerdas, terhubung data, personalisasi berbasis AI
Fakta menarik: halaman web pertama di dunia dibuat tahun 1991 dan masih bisa diakses hari ini di info.cern.ch — isinya hanya teks dan tautan, tanpa gambar maupun warna.

Bagaimana Web Bekerja

dasar
Ketika kamu mengetik alamat website di browser, terjadi percakapan singkat antara client (perangkatmu) dan server (komputer penyimpan website). Alur sederhananya seperti berikut:
LangkahYang Terjadi
1. RequestBrowser mengirim permintaan ke server, misalnya "tolong kirim halaman index.html"
2. ProsesServer mencari file yang diminta, kadang perlu mengambil data dari database
3. ResponseServer mengirim balik file HTML, CSS, JS, gambar, dsb. ke browser
4. RenderBrowser menyusun dan menampilkan file tersebut menjadi halaman yang kita lihat
Istilah penting: protokol yang dipakai untuk percakapan ini disebut HTTP (HyperText Transfer Protocol), atau HTTPS jika sudah terenkripsi dan lebih aman.

Macam-Macam Website

dasar
Website dapat dibedakan dari cara kontennya dihasilkan maupun dari fungsinya.
JenisPenjelasanContoh
Website StatisIsinya tetap, tidak berubah kecuali diedit manual oleh pembuatnyaCompany profile sederhana
Website DinamisIsinya berubah otomatis berdasarkan data di databaseToko online, berita
Web AplikasiBerfungsi seperti aplikasi penuh, sangat interaktifGoogle Docs, Canva
Portal / MediaBerfokus menyajikan banyak artikel/beritaSitus berita
E-CommerceKhusus untuk jual-beli onlineMarketplace

Tiga Bahasa Inti Web

dasar
Hampir semua halaman web dibangun dari kombinasi tiga bahasa berikut. Ibaratkan seperti membangun rumah:
BahasaAnalogiFungsi
HTMLKerangka & dinding rumahMenentukan struktur dan isi konten halaman
CSSCat, dekorasi, tata ruangMengatur tampilan visual: warna, jarak, tata letak
JavaScriptListrik & saklar rumahMembuat halaman merespons aksi pengguna (interaktif)
Urutan belajar yang disarankan: HTML dulu untuk memahami struktur, lalu CSS untuk mempercantik, baru JavaScript untuk membuatnya hidup. Modul ini disusun mengikuti urutan tersebut, mulai Bab 02.
Bab 02

HTML — Struktur Halaman Web

HTML (HyperText Markup Language) adalah bahasa dasar untuk menyusun isi sebuah halaman web: judul, paragraf, gambar, tabel, hingga formulir.

Konsep Dasar HTML

dasar
Kode HTML tersusun dari tag, biasanya berpasangan seperti <p> dan </p>. Setiap dokumen HTML memiliki struktur dasar wajib: <html> sebagai pembungkus, <head> untuk informasi halaman, dan <body> untuk isi yang tampil. HTML dijalankan langsung oleh browser tanpa perlu server.

Hasil
Coba: ubah teks di dalam <h1> lalu tekan tombol Jalankan untuk melihat perubahannya secara langsung.

Heading, Paragraf & Format Teks

dasar
HTML punya 6 tingkat judul, dari <h1> (terbesar) sampai <h6> (terkecil). Untuk format teks tersedia <b> tebal, <i> miring, <u> garis bawah, <sup> superscript, dan <sub> subscript.

List dalam Dokumen HTML

dasar
Ada dua jenis daftar: <ul> (unordered list, ditandai bulatan) dan <ol> (ordered list, ditandai angka). Setiap butir daftar ditulis dengan <li>.

Tabel pada Halaman Web

Elemen Multimedia

menengah
Multimedia adalah gabungan lebih dari satu jenis media — gambar, audio, dan video — dalam satu halaman. Browser modern sudah punya elemen HTML5 bawaan untuk menampilkannya tanpa plugin tambahan. Berikut pembahasan tiap jenis media, lengkap dengan perbandingan sumber lokal (file sendiri) dan online (tautan internet).
1

Menyisipkan Gambar (Lokal & Online)

Gambar disisipkan dengan <img>. Nilai atribut src bisa berupa path file lokal (gambar satu folder dengan file HTML) atau URL online (tautan langsung ke gambar di internet). Atribut alt wajib diisi sebagai teks pengganti jika gambar gagal dimuat, dan penting untuk aksesibilitas. Gambar juga bisa dijadikan tautan dengan membungkusnya di dalam tag <a>.
editor.html
Hasil
AtributNilai contohFungsi
src"gambar/foto.jpg" / "https://..."Sumber gambar (lokal atau online)
alt"Deskripsi gambar"Teks alternatif jika gambar tidak tampil
width / height"260"Ukuran tampil gambar (piksel)
Tips: untuk gambar lokal, simpan file dalam folder proyek (misal folder gambar/) lalu tulis path relatifnya di src — jangan alamat folder komputer sendiri (mis. C:\Users\...) karena tidak akan terbaca di komputer lain.
2

Menyisipkan Audio (Lokal & Online)

Elemen <audio> menerima file lokal lewat tag <source>, atau tautan file audio online langsung di atribut src, selama server tujuan mengizinkan file tersebut diputar langsung di browser. Atribut controls menampilkan tombol putar/jeda/volume.

Menyisipkan Video (Lokal & Online)

Elemen <video> dipakai untuk file video sendiri (lokal) melalui tag <source>, lengkap dengan atribut controls. Untuk video dari platform seperti YouTube, digunakan <iframe> dengan URL versi "embed", bukan tag <video>.

CSS — Mendesain Tampilan

CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan elemen HTML, mulai dari warna, ukuran, jarak, tipografi, latar belakang, border, hingga layout responsif. Materi bab ini diperluas berdasarkan materi CSS pada PDF yang kamu kirim.

Konsep Dasar CSS & Cascading Style Sheets

dasar
CSS bukan bahasa pemrograman, melainkan bahasa untuk mengatur presentasi halaman web. Aturan CSS ditulis dengan pola selector { property: value; }. CSS dapat diterapkan melalui internal, inline, external, dan @import. Dalam konsep cascading, aturan yang lebih spesifik atau memiliki prioritas lebih tinggi dapat mengalahkan aturan lain.

Bab 05

Basis Data

Website dinamis butuh tempat menyimpan data yang bisa diubah kapan saja tanpa mengedit kode — di sinilah basis data (database) berperan. Karena database berjalan di server, materi ini bersifat konsep dan contoh kode saja, tanpa live preview.

Konsep Basis Data

dasar
Basis data adalah kumpulan data yang disusun rapi dalam tabel, mirip spreadsheet. Setiap tabel punya kolom (field, misalnya nama, umur) dan baris (record, satu data lengkap).
IstilahAnalogi ExcelContoh
DatabaseFile Exceldb_sekolah
TabelSheet/lembar kerjasiswa
Kolom (field)Judul kolomnama, kelas, nilai
Baris (record)Satu baris data1, Ahmad, XI TKJ 1, 90

Pengenalan MySQL

menengah
MySQL adalah salah satu sistem basis data paling populer untuk website, sering dipasangkan dengan PHP. Perintah untuk mengelola data ditulis dalam bahasa SQL (Structured Query Language).
buat_tabel.sql
CREATE TABLE siswa (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nama VARCHAR(50),
  kelas VARCHAR(20),
  nilai INT

Query CRUD Dasar

lanjut
CRUD adalah 4 operasi dasar terhadap data: Create (tambah), Read (baca), Update (ubah), Delete (hapus).
OperasiPerintah SQLFungsi
CreateINSERT INTO siswa VALUES (...)Menambahkan data baru
ReadSELECT * FROM siswaMenampilkan/membaca data
UpdateUPDATE siswa SET nilai=95 WHERE id=1Mengubah data yang sudah ada
DeleteDELETE FROM siswa WHERE id=1Menghapus data
Catatan: pada aplikasi nyata, query ini dijalankan lewat bahasa server seperti PHP, lalu hasilnya dikirim ke halaman HTML untuk ditampilkan ke pengguna.
Bab 06

Server

Bab penutup ini menjelaskan tempat website "tinggal" agar bisa diakses banyak orang lewat internet.

Client vs Server

dasar
Client adalah perangkat pengguna (laptop, HP) yang meminta halaman web. Server adalah komputer yang menyimpan file website dan mengirimkannya saat diminta. Kode yang berjalan di browser (HTML, CSS, JS) disebut client-side; kode yang berjalan di server (PHP, database) disebut server-side.
SisiDijalankan diContoh Bahasa
Client-sideBrowser penggunaHTML, CSS, JavaScript
Server-sideKomputer serverPHP, Node.js, Python, MySQL

Web Server & Hosting

menengah
Web server adalah program yang bertugas melayani permintaan halaman (misalnya Apache atau Nginx). Hosting adalah layanan penyewaan tempat penyimpanan agar website bisa diakses online 24 jam, dan domain adalah nama alamat website (seperti sekolahku.sch.id) yang menggantikan alamat IP yang sulit diingat.
IstilahPenjelasan
LocalhostServer lokal di komputer sendiri, untuk latihan/uji coba (mis. XAMPP)
HostingSewa penyimpanan online supaya website bisa diakses publik
DomainNama alamat website yang mudah diingat manusia
DNSSistem yang menerjemahkan nama domain menjadi alamat IP server
Untuk latihan di sekolah: aplikasi seperti XAMPP atau Laragon memungkinkan komputer sendiri berperan sebagai server (localhost), cocok untuk belajar PHP dan MySQL sebelum website diunggah ke hosting sungguhan.
